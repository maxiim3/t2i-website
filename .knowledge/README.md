# Knowledge Base

This directory contains project documentation, decisions, and guidelines for the T2I marketing website.

## Structure

- `decisions/` - Technical and business decisions with rationale
- `rules/` - Development rules and constraints
- `context/` - Project context and background information
- `guidelines/` - Design system and development guidelines

## Purpose

This knowledge base helps maintain consistency, provides context for future development, and documents the reasoning behind key decisions.
