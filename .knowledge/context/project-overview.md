# T2I Marketing Website Project Overview

## Project Mission
Create a high-performance marketing website for T2I that clearly positions it as a text-to-image utility tool (NOT an AI art generator) and drives qualified traffic to the PWA application.

## Business Context

### What T2I Is
- **Utility tool** that converts text into PNG/JPG/WebP images
- **Simple text rendering** with font, color, and background options
- **Client-side processing** - no server involvement
- **Free to use** with no authentication required

### What T2I Is NOT
- **AI art generator** (critical distinction)
- **Artistic interpretation tool**
- **Complex image creation platform**

## Dual-Domain Architecture

### t2i.app (This Repository)
- **Purpose**: SEO-optimized marketing site
- **Goal**: Drive discovery and conversions
- **Content**: Static pages, landing pages, trust content
- **Indexing**: Fully indexable by search engines

### create.t2i.app (Separate Repository)
- **Purpose**: The actual PWA application
- **Goal**: Provide the text-to-image functionality
- **Content**: Interactive editor and canvas
- **Indexing**: noindex, follow (not for SEO)

## Target Audience

### Primary Users
- Social media managers creating quote graphics
- Developers needing text rendered as images
- Content creators making thumbnails
- Business users creating simple graphics

### Search Intent
- "convert text to image" (2,900 monthly searches)
- "text to PNG" (1,300 monthly searches)
- "text to JPG" (890 monthly searches)
- "text as image" (720 monthly searches)

## Success Metrics
- **Traffic**: Drive organic visitors to marketing site
- **Conversions**: Get users to create.t2i.app
- **SEO**: Rank for utility-focused keywords
- **Clarity**: Avoid AI art confusion

## Current Phase
**MVP Sprint** (2 weeks)
- 3 essential pages: Homepage, Text-to-PNG landing, FAQ
- Focus on fastest path to market
- Measure and iterate based on real data
